## 2. KEYWORD MATCHING SUB-PROCESS

```
┌─────────────────────────────────────────────────────────────────┐
│                 KEYWORD MATCHING PROCESS                        │
└─────────────────────────────┬───────────────────────────────────┘
                              │
                              ▼
                  ┌───────────────────────────┐
                  │   Start Keyword Search   │
                  └───────────┬───────────────┘
                              │
                              ▼
                  ┌───────────────────────────┐
                  │   Get Priority Order      │
                  │   List of Categories      │
                  └───────────┬───────────────┘
                              │
                              ▼
              ┌───────────────────────────────┐
              │   Get First Category         │
              │   from Priority List         │
              └───────────┬───────────────────┘
                              │
                              ▼
              ┌───────────────────────────────┐
              │   Get Keywords for            │
              │   This Category               │
              └───────────┬───────────────────┘
                              │
                              ▼
                  ┌───────────────────────────┐
                  │   For Each Keyword in     │
                  │   Category Keywords       │
                  └───────────┬───────────────┘
                              │
                              ▼
              ┌───────────────────────────────┐
              │   Create Regex Pattern       │
              │   (with word boundaries)      │
              │   pattern = "\b" + keyword    │
              └───────────┬───────────────────┘
                              │
                              ▼
                  ┌───────────────────────────┐
                  │   Search Input Text      │
                  │   (Case-insensitive)     │
                  └───────────┬───────────────┘
                              │
                              ▼
              ┌───────────────────────────────┐
              │   Match Found?                │
              └───────────┬───────────────────┘
                    Yes    │    No
                    ┌──────┴──────┐
                    ▼             ▼
          ┌─────────────┐  ┌─────────────────────┐
          │ Return True │  │ More Keywords?       │
          │ Return      │  └──────────┬──────────┘
          │ Response    │     Yes ────┼──── No
          └─────────────┘     │       │
                    ▲         ▼       ▼
                    │   ┌─────────────────────┐
                    │   │ Get Next Keyword    │
                    │   │ (Loop back)         │
                    │   └─────────────────────┘
                    │         │
                    │         ▼
                    │   ┌─────────────────────┐
                    └───│ Next Category?       │
                        └──────────┬──────────┘
                           Yes ────┼──── No
                                   │
                                   ▼
                         ┌─────────────────┐
                         │ Return False    │
                         │ Return Fallback │
                         └─────────────────┘
```

```
┌─────────────────────────────────────────────────────────────────┐
│                    INPUT PREPROCESSING                           │
└─────────────────────────────┬───────────────────────────────────┘
                              │
                              ▼
                  ┌───────────────────────────┐
                  │   Get Raw User Input      │
                  │   Example: "  ADMISSION   │
                  │           Process??  "    │
                  └───────────┬───────────────┘
                              │
                              ▼
                  ┌───────────────────────────┐
                  │   Step 1: Convert to      │
                  │   Lowercase               │
                  │   Result: "  admission   │
                  │           process??  "    │
                  └───────────┬───────────────┘
                              │
                              ▼
                  ┌───────────────────────────┐
                  │   Step 2: Remove Extra    │
                  │   Whitespace              │
                  │   Result: "admission     │
                  │           process??"      │
                  └───────────┬───────────────┘
                              │
                              ▼
                  ┌───────────────────────────┐
                  │   Step 3: Apply Typo      │
                  │   Corrections             │
                  │   (Using Dictionary)      │
                  │                           │
                  │   "admission " →          │
                  │     "admissions "         │
                  │   "fees" → "fee"          │
                  │   "eligibilty" →          │
                  │     "eligibility"        │
                  └───────────┬───────────────┘
                              │
                              ▼
                  ┌───────────────────────────┐
                  │   Return Processed Input  │
                  │   Example: "admissions    │
                  │           process??"      │
                  └───────────────────────────┘
```
